# HTML & CSS Landing Page Collection

A collection of three clean, responsive, and semantic web landing pages built using modern HTML5 and standard CSS3.

---

## 📁 Projects Overview

### 1. Butter & Bloom Bakery
A warm, inviting landing page tailored for a local artisan bakery and cafe.
* **Key Features:** Hero section with call-to-action, product card grid with pricing, photo gallery grid, custom order banner, and store hours/contact details.
* **Theme & Style:** Warm earth tones (`--ink`, `--berry`, `--cream`, `--peach`, `--gold`), serif typography (`Georgia`), rounded card styling.
* **Files:** `index.html` (or `bakery.html`), `sample.css`

---

### 2. Clearview Health Clinic
A professional, accessible web page for a medical practice with doctor profiles and appointment booking options.
* **Key Features:** Distinct navigation bar with action buttons, care team doctor cards with scheduling info, interactive consultation time slots, multi-field appointment request form, and new patient registration form with consent checkboxes.
* **Theme & Style:** Clean clinical palette (`--navy`, `--teal`, `--mint`, `--paper`), structured card components, fully accessible form inputs.
* **Files:** `clinic.html`, `simple.css`

---

### 3. Still & Root Yoga Studio
A minimalist, serene landing page designed for a wellness center or yoga studio.
* **Key Features:** Full-bleed hero banner, practice overview grid, teacher/instructor bios, interactive weekly class schedule table, membership pricing cards, and wellness journal article list.
* **Theme & Style:** Calming natural palette (`--ink`, `--sage`, `--cream`, `--clay`), structured grid layouts, elegant typography.
* **Files:** `yoga.html`, `style.css`

---

## 🚀 Getting Started

### Prerequisites
No external dependencies or build tools required! These projects run directly in any standard modern web browser.

### Running the Projects
1. Clone or download the repository to your local machine.
2. Open any of the HTML files directly in your web browser:
   * Double-click `bakery.html`, `clinic.html`, or `yoga.html`.
   * Alternatively, right-click the file and select **Open with** > **Google Chrome** (or your preferred browser).

---

## 🛠️ Built With

* **HTML5:** Semantic elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<nav>`, `<form>`).
* **CSS3:** Native CSS variables (`:root`), Flexbox layout, CSS Grid, media queries for responsive design.
* **External Assets:** High-resolution royalty-free imagery provided via [Unsplash](https://unsplash.com).

---

## 📱 Responsive Design

All three templates are fully responsive out of the box and tested for mobile devices:
* Single-column layouts for small screen viewports (`<= 700px` / `<= 760px`).
* Fluid image scaling (`object-fit: cover`).
* Touch-friendly button sizes and form inputs.
